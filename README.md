# Risetin Android

Unduhan resmi **Risetin Android**: lanjutkan proyek naskah jurnal dari HP.
Aplikasi ini membuka folder riset yang sama dengan Risetin Desktop (misalnya
folder Google Drive), lengkap dengan percakapan dan file yang diizinkan untuk AI.
Berkas riset tidak diunggah ke server Risetin.

Repo ini hanya berisi rilis aplikasi. Situs dan akun: **https://risetin.id**

## Pasang (Android 7 ke atas)

1. Di HP, unduh **`Risetin-Android.apk`** dari halaman
   [Releases](https://github.com/codeboosterid/risetin-android/releases/latest)
   atau dari https://risetin.id.
2. Buka berkasnya dari unduhan. Bila diminta, izinkan browser memasang aplikasi.
3. Buka Risetin, ketuk **Masuk dengan Google**, lalu **Izinkan**.

Cocokkan berkasnya dengan `SHA256SUMS` di halaman rilis bila perlu.

## Mulai

1. Di laptop, buka proyek di Risetin Desktop dan aktifkan **Lanjutkan di HP**.
2. Di HP, ketuk **Buka folder proyek** dan pilih folder yang sama.
3. Lanjutkan percakapan. Kuota paketnya sama dengan Risetin Desktop.

Bantuan: support@risetin.id
